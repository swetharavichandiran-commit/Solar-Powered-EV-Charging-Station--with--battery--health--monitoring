# 🔋 Solar-Based EV Charging Station with Battery Health Monitoring

## 📖 Overview

This project is a smart Solar-Based EV Charging Station that charges an electric vehicle using solar energy while continuously monitoring the battery's health. A mobile application displays real-time battery information, helping users monitor charging status and battery condition.

## ✨ Features

- ☀️ Solar-powered EV charging
- 🔋 Battery health monitoring
- 📱 Mobile app for real-time monitoring
- ⚡ Battery voltage monitoring
- 🔌 Charging status indication
- 🌡️ Battery temperature monitoring
- 📊 Real-time battery data display
- 🚨 Battery protection and safe charging

## 🛠️ Technologies Used

- ESP32
- Embedded C
- C Programming
- IoT
- Mobile Application
- Voltage Sensor
- Current Sensor
- Temperature Sensor

## 📱 Mobile Application

## 🎯 Objectives

- Promote renewable energy through solar charging.
- Improve battery life using continuous health monitoring.
